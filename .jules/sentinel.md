## 2024-05-15 - Local File Inclusion (LFI) in WebViewClient
**Vulnerability:** `WebViewClient.shouldInterceptRequest` allowed arbitrary `file://` URLs, potentially exposing internal app data or system files via path traversal or direct file requests in `AdBlockWebViewClient`.
**Learning:** Naive `startsWith("file://")` checks without canonical path validation or handling URL-encoded traversal sequences (`%2e%2e`) are easily bypassed. `android_asset` exceptions must also strictly prohibit `..` sequences. Furthermore, `mLoadedUrls` map was using a non-thread-safe `HashMap` in a multi-threaded context, risking `ConcurrentModificationException` leading to DoS.
**Prevention:** Always use `Uri.parse(url).getPath()` to decode the path before creating a `File` object. Use `getCanonicalPath()` to strictly validate that the requested file resides within the intended base directory (e.g., `cacheDir.getCanonicalPath()`). Use `ConcurrentHashMap` for caching state in `WebViewClient` methods.
