## 2024-05-24 - [Persisting JavascriptInterface Vulnerability]
**Vulnerability:** A `PdfAndroidJavascriptBridge` JavascriptInterface injected into a WebView could persist after navigating from the trusted PDF viewer URL to an untrusted external URL. This would expose Java methods (like `getChunk`, `getSize`, `onLoad`, `onFailure`) to arbitrary web pages, leading to potential Cross-Site Scripting (XSS) or Data Exfiltration.
**Learning:** `removeJavascriptInterface` was only being called immediately before adding the new interface in `reloadUrl`. Navigating to a new URL via user interaction (e.g. clicking a link in a web page loaded after the PDF) or back/forward history would not trigger `reloadUrl`, leaving the interface attached to the WebView context.
**Prevention:** `removeJavascriptInterface` should be called proactively during page transitions, specifically within `WebViewClient.onPageStarted`, conditionally removing the interface if the target URL is not the trusted origin (e.g., `PDF_LOADER_URL` or `about:blank`).
