## 2024-05-18 - WebView LFI via Interception Overrides
**Vulnerability:** AdBlockWebViewClient intercepted all WebView requests, allowing malicious `file://` URIs (Local File Inclusion/Path Traversal) to bypass native Chromium security.
**Learning:** Overriding `shouldInterceptRequest` forces the app to manually validate the security of the requests. If a scheme like `file://` isn't explicitly checked against a safe canonical path, standard LFI vulnerabilities arise, potentially leaking sensitive app data. In addition, Chromium WebViews invoke `shouldInterceptRequest` on background threads, causing `ConcurrentModificationException` and thread-safety bugs if standard Java Maps (like `HashMap`) are used for shared caches across requests.
**Prevention:** Always use `ConcurrentHashMap` for caches accessed inside `shouldInterceptRequest`. Always explicitly check the scheme (`file://`) and validate the resulting `File.getCanonicalPath()` against allowed directories (like cache dir and `/android_asset/`) before processing or returning `super.shouldInterceptRequest`.
