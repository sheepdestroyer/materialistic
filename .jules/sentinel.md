## 2025-05-22 - [LFI via WebView setAllowFileAccess]
**Vulnerability:** `setAllowFileAccess(true)` was enabled by default in `CacheableWebView`, allowing untrusted web content to potentially access local files via `file://` scheme if a vulnerability like LFI or open redirect exists in the loaded content, or if the user is tricked into loading a file URL.
**Learning:** `WebView` maintains stateful settings that can be reset during reload operations (e.g., `loadUrl("about:blank")` -> `loadUrl(mPendingUrl)`). Security settings must be robustly re-applied or persisted across these transitions. Specifically, `WebView.reloadUrl` uses a two-step process involving `about:blank`, which can race with or overwrite settings if not handled carefully.
**Prevention:** Disable `setAllowFileAccess` by default. Only enable it when strictly necessary (e.g., loading a known safe local file) and ensure the check validates the file path against a trusted directory (like the app's cache directory).
