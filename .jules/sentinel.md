## 2025-02-23 - Prevent LFI in WebFragment PDF Javascript Bridge
**Vulnerability:** A Local File Inclusion (LFI) vulnerability existed in `WebFragment.PdfAndroidJavascriptBridge`. The class allowed arbitrary file paths to be passed from the javascript interface to read local files by directly constructing a `File` object and returning chunks using a `RandomAccessFile`. Since `allowFileAccess` is enabled by default to load `file:///android_asset` files and cached archive files, an attacker could load the viewer with a crafted path traversing outside of the intended directory and steal arbitrary local application files.
**Learning:** In Android WebViews, when `allowFileAccess` is set to true, Javascript Interfaces that expose local file reading capabilities must strictly validate that the requested path falls within the intended constraints (such as the app's cache directory).
**Prevention:** Always perform canonical path validation when constructing `File` objects inside Javascript Interfaces that expose file contents. Ensure the `getCanonicalPath()` starts with the trusted directory path (`cacheDir.getCanonicalPath() + File.separator`).
