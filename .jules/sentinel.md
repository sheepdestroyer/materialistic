## 2024-05-24 - File Access Control in Cacheable WebViews
**Vulnerability:** `CacheableWebView` explicitly enabled `setAllowFileAccess(true)` to support loading saved web archives (`.mht` files). However, `AdBlockWebViewClient` did not validate `file://` scheme URLs, potentially allowing malicious loaded pages or iframes to access any exported local file (e.g. `file:///data/data/.../databases/app.db`) through path traversal or direct access.
**Learning:** Even when local file access is required for a specific feature (like web archives), you must not leave `shouldInterceptRequest` open to all `file://` URLs.
**Prevention:** Intercept all `file://` URLs in `WebViewClient.shouldInterceptRequest`, parse them with `Uri.parse().getPath()`, resolve their canonical path via `File.getCanonicalPath()`, and enforce strict prefix matching (e.g., against `getCacheDir().getCanonicalPath() + File.separator` or `/android_asset/`). Default to blocking the request if validation fails.
