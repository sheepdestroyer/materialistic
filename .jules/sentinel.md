## 2025-02-27 - [Mitigate Local File Inclusion in WebViews]
**Vulnerability:** `CacheableWebView` explicitly enabled `setAllowFileAccess(true)`, exposing the app to Local File Inclusion (LFI) via malicious `file://` URLs. The ad-blocking interception in `AdBlockWebViewClient` also used a non-thread-safe `HashMap`, risking crashes during background URL interception.
**Learning:** The application requires file access specifically to load `.mht` cache files for offline reading. However, globally enabling `setAllowFileAccess(true)` is dangerous. The correct approach is to disable global file access and selectively serve valid cache files using `WebResourceResponse` interception, validating canonical paths to prevent traversal.
**Prevention:** Always use `setAllowFileAccess(false)` in WebViews. Implement specific file loading mechanisms through `shouldInterceptRequest`, ensuring canonical path validation against designated secure directories (e.g., `getCacheDir()`). For shared maps in background `WebViewClient` methods, use thread-safe collections like `ConcurrentHashMap`.
